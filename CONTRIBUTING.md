# Como contribuir

1. Abra uma issue descrevendo a tarefa ou o defeito.
2. Crie uma branch a partir da `main` com o nome `tipo/descricao` (ex.: `feat/busca-por-autor`).
3. Faça commits pequenos, com mensagens claras.
4. Abra um pull request e escreva `Closes #numero` na descrição.
5. Aguarde a revisão de quem é dono do código (veja `.github/CODEOWNERS`).
